# Mails by Kotogo — téléchargements

Ce dépôt ne contient pas de code : il sert uniquement à distribuer les installeurs de
l'application **Mails by Kotogo**.

## Télécharger

Les installeurs sont dans l'onglet **[Releases](../../releases)** :

| Système | Fichier | Installation |
|---|---|---|
| macOS (Apple Silicon et Intel) | `.dmg` | Ouvrir le fichier, puis glisser « Mails by Kotogo » dans Applications. |
| Windows 10 / 11 (64 bits) | `-setup.exe` | Lancer l'installeur. Aucun droit administrateur nécessaire. |

## Au premier lancement sur macOS

L'application est signée avec un certificat interne, mais pas notarisée par Apple. macOS la
bloque donc une première fois :

**Réglages Système → Confidentialité et sécurité → « Ouvrir quand même »**

Une seule fois : les lancements suivants ne demandent plus rien.

## Vos données

Les comptes, règles, catégories et le suivi ne sont pas stockés dans l'application. Ils sont
conservés d'une version à l'autre lors des mises à jour.
